# JsonExampleProject

## Aprašymas

Projektas sukurtas kaip .NET konsolės programa, naudojant Newtonsoft.Json biblioteką JSON failų nuskaitymui ir paveldimumui modeliuoti.

## Užduotys:

- ✅ Sukurtas `users.json` failas su pradiniais vartotojais
- ✅ Sukurtas `user_types.json` su rolėmis (Admin ir Naudotojas)
- ✅ Pridėtas XML skaitymas
- ✅ Sukurtos klasės: `User`, `Admin`, `StandardUser`
- ✅ Nuskaitymas, pridėjimas ir atvaizdavimas konsolėje

## Paleidimo instrukcija

1. Paleisti `Program.cs` Visual Studio aplinkoje
2. Įsitikinti, kad `users.json` ir `user_types.json` yra projekte su nustatyta savybe:
   - **Copy to Output Directory → Copy if newer**
